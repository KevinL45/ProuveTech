## 📦 Dépendances utilisées

Voici les principales dépendances utilisées dans ce projet **Spring Boot 3.4.4** avec **Java 21** :

### 🚀 Dépendances essentielles
- **Spring Boot Web** → API REST (`spring-boot-starter-web`)
- **Spring Boot JPA** → ORM & Base de données (`spring-boot-starter-data-jpa`)
- **MySQL DRIVER** → MySQL (`mysql-connector-j`)
- **Lombok** → Réduction du boilerplate (`lombok`)

### 🔐 Sécurité et Authentification
- **Spring Security** → Authentification et protection des routes (`spring-boot-starter-security`)

### 🛠 Outils de développement
- **Spring Boot DevTools** → Reload automatique (`spring-boot-devtools`)

### 🔒 Gestion des secrets
- **Spring Dotenv** → Utilisation d’un fichier `.env` (`spring-dotenv`)
